07 / Architecture insight

CPU 架构洞察

State pressure状态不是免费内存

Event log、context derive、serialization 与 compaction 会随表面节点和上下文尺寸改变 CPU 工作形态。

Boundary cost边界本身是 workload

Tool dispatch、process lifecycle、provider policy 与 code execution 把一次意图切成多个 Host-side execution boundary。

Scale behavior并发改变资源曲线

多 Agent 不只增加吞吐，也会引入调度、进程与共享 CPU pool 的效率变化。

Interpretation机制先于排名

报告描述可重现的机制与成本结构，不把单一 fixture 的结果外推成“谁更可靠”。
