07 / 对通用 CPU 的启示

以下是研究方向，不是跨 CPU 排名

推断状态工作集值得关注

Event log、context derive、serialization 与 compaction 随节点和字节增长，提示 cache/memory working set 是后续硬件实验方向。

推断执行边界本身有成本

Tool dispatch、process lifecycle、policy 与 code runtime 把一次意图切成多个 Host-side execution boundary。

推断并发改变资源曲线

多 Agent 同时增加吞吐、驻留内存和调度压力；单机 n=5 knee 不能直接外推。

限制机制先于排名

报告描述 pinned fixture 下可追溯的机制和成本结构，不声称某类 CPU 或 runtime 普遍更优。
